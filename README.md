# AI-Fitness-club-2025
Gym registration app
🏋️ AI Fitness Club 2025

A simple Gym Management Web App built using Streamlit.

🚀 Features

- 🧑 Member Registration
- 📋 View Members List
- 💰 Membership Plans Display
- 📊 Easy Data Management

🛠️ Tech Used

- Python
- Streamlit
- Pandas

📦 Installation

1. Clone the repository:

git clone https://github.com/your-username/ai-fitness-club-2025.git

2. Install dependencies:

pip install -r requirements.txt

3. Run the app:

streamlit run app.py

📁 Project Structure

ai-fitness-club-2025/
│── app.py
│── requirements.txt
│── members.csv
